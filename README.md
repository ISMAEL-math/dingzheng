# 钉正 · 学习工作台

一个本机运行的自动批改与错题复习第一版。

## 启动

```sh
npm start
```

打开 http://localhost:4173。

先运行 `npm install`。也可以把 `.env.example` 复制为 `.env`，填写 `SILICONFLOW_API_KEY`；或者在应用设置中填写。浏览器中保存的 Key 优先。MinerU API Key 可在“模型与设置 → PDF 解析”中填写，也可配置在本地 `.env`；未填写时使用 MinerU 免密服务（单个 PDF 上限 10 MB、20 页）。密钥不会写入代码仓库或导出备份。

## 已实现

- 错题本支持自定义科目、多个错题本和标签；旧错题按已有科目归类。批改结果中勾选题目后选择分类再收录，可修改单题或批量分类。按科目、错题本、标签、掌握状态及关键词组合筛选，打印筛选结果或勾选题目。

- 知识库 PDF 提供“文本提取”和“MinerU”两种方式。文本提取在本机读取 PDF 自带文字；MinerU 解析扫描页、版面、表格和公式。处理完成后自动切分、生成向量并加入检索，不需要逐页校对。
- LlamaIndex 管理 embedding 调用和向量检索；可在设置中选择 Qwen3 Embedding 或 BGE-M3 系列模型。
- 对话输入支持粘贴或添加图片、PDF，也支持拖入文件。聊天中的 PDF 按“PDF 解析”设置读取后作为本轮附件发送；可从附件卡片主动存入知识库，供后续检索。发送照片时自动使用图片理解模型。
- 上传一张或多张作业照片，由 SiliconFlow 视觉语言模型识别题目和手写答案，再由 SiliconFlow 对话模型逐题批改。有知识库资料时，批改前会匹配同一道题，按资料原文补齐缺失题干、选项或条件；找不到可靠同题或发生冲突时保留识别内容。
- 教材库可导入 PDF 并在服务端后台调用 MinerU，保存原 PDF、MinerU Markdown/归档产物、页码章节结构和待核验题目。只有人工核验、答案与页码完整的题目发布后，才会参与精确题目匹配和客观题判分；教材正文会同步到当前浏览器的知识库用于讲义检索。
- 结果页可使用“用知识库补全题面”为旧记录补全并重新批改，同步已收录错题。补全保留原卷识别原文和资料出处，不补写学生作答，不用相似题替换原题。
- 逐张照片识别、逐题检索和批改，保存每题对应的照片；结果页展示全部照片。
- 编辑题干、学生作答、参考答案、解释与判定，可更换关联照片并拖动裁题；同步更新已收录错题。改判正确后保留错题并标为已掌握。
- 从错题本选题，在屏幕上重新作答并自动批改；保存掌握状态。
- 本地 IndexedDB 保存资料、照片、记录和错题；支持导出及导入 JSON 备份。导入前校验，确认后替换学习数据，保留当前 Key 与模型设置；兼容旧版导出。
- 设置页可从硅基流动账号读取并选择聊天、视觉和 embedding 模型，也支持手动输入模型 ID；提供照片模型试跑。默认视觉模型为 Qwen3-VL-32B-Instruct。旧版已下线的 Qwen2.5-VL 默认值会自动迁移。

## 注意

- 使用文本提取时，扫描图片里没有文字层的页面无法提取；请改选 MinerU。MinerU 会将 PDF 发送到 MinerU 服务。配置 MinerU API Key 后单份文件上限为 200 MB、200 页；免密服务限制为 10 MB、20 页。
- 更换 embedding 模型后，应在知识库中点击“重建索引”。旧版资料和备份仍可继续使用。
- 模型服务请求通过本机 Node 服务转发。浏览器内填写的 Key 保存在本机浏览器数据库中，也可用 `.env` 配置服务端 Key。
- 本地数据只存在于当前浏览器配置中。清除浏览器数据会删除它；重要资料请导出备份。
- 教材原件和结构化题库保存在运行服务的 `.local/textbook-library/`，不会进入浏览器备份。导入扫描版教材需要 MinerU 可用；配置 MinerU Key 后支持 200 MB / 200 页，免密服务受 MinerU 的 10 MB / 20 页限制。启用 AI 清洗还需要在应用中配置可用聊天模型与凭证；未配置时会跳过清洗并保留规则提取草稿。

## 教材库工作流

从左侧“教材库”上传 PDF 后，服务端排队执行 MinerU 解析、章节与页码构建、题目切分、答案关联和质量检查。处理状态、失败步骤和已完成检查点会保存到本机；失败任务可从对应步骤重试。每本书按 PDF 内容指纹去重，同名的不同版本会分别保存。

项目目前没有独立的关系数据库或现成的 `answer_index.md`。题库数据以每本书的 `book.json`、`questions.json` 和 `document-pages.json` 保存；目前目录中的 PDF 也不会自动被当作可信答案源。导入器从 MinerU Markdown 生成待核验候选，教材答案与官方解析只在能关联原文页码时作为教材字段显示。请在“检查与编辑”中对照原 PDF 核验题干、选项、答案及页码，再发布题库。仅凭题号或文本相似度不会判为同一道题。

完成解析的教材正文会加入当前浏览器的知识库并复用已有混合检索（BM25 关键词与已配置的向量召回）；没有向量 API 时仍可用 BM25。题目候选只参与讲义知识检索，不会成为批改标准答案。清除浏览器数据后，再打开教材库会从本机教材文件重建该浏览器的讲义索引。

## 本轮可靠性修复

- 知识库先在所选资料的全部片段中计算相似度，再筛选排序，不再只对前 8 段进行向量检索。批改按题检索，无相关结果时不硬塞参考资料。
- 检索相似度门槛目前为启发式值，仍需用真实题目评估。没有向量、向量模型不一致或请求失败时使用文字匹配。旧资料没有记录嵌入模型，请在知识库点击“重建检索”；切换嵌入模型后也需重建。
- 新建或重新解析的 PDF 会保留标题路径、页码、目录页和约 140 字符的相邻片段重叠；知识库预览可检查抽取出的标题结构。旧资料需要点“重新解析并重建结构”，仅更新向量索引不会补出结构元数据。
- 检索使用向量与 BM25 风格关键词分数做 Reciprocal Rank Fusion。章节/目录/全书概览问题会优先附上整份资料的标题结构；知识库对话可调用检索工具继续改写查询和补充证据，最终回答引用资料编号、文件名与页码。
- 查询向量请求只发送本地预筛出的候选片段，避免把整本书的全部向量反复塞进一次请求；若向量不可用，会记录诊断并回退到关键词召回。
- 最近 12 条对话中包含照片时自动使用图片理解模型。
- 旧版多页批改无法可靠推断每道题来自哪张照片，显示为“照片待关联”，可通过“编辑与裁题”指定，不再默认使用第一张照片。
- 逐题批改会增加 API 请求次数；当前版本尚未用真实样本评估耗时、费用和准确率。
- 导入恢复为整份替换，不合并重复记录；单次备份文件上限为 200 MB。恢复失败时保留原数据，恢复前建议先导出当前记录。
